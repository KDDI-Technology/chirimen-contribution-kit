# ドライバ追加 入力シート（雛形）

**使い方**: このファイルをコピーして `devices/<device>.driver.md` として保存し、
`[ ]` で囲まれた部分をご自身の内容に書き換えてください（`[ ]`自体も削除してください）。
各項目の行末に `（必須）` / `（任意）` を明記しています。`（任意）`の項目は、該当しない・
不明な場合はその行ごと削除して構いません（削除した場合の扱いは各項目の説明を参照）。
ClaudeCodeが処理する際に、必須項目の不足があれば確認します。見出しやラベルの文言・順序は
変更しないでください。

社内ステージングForkのURLは組織で固定のため、この入力ファイルには記入しません
（`CHIRIMEN_DRIVER_CONTRIBUTION.md`の「1. 対象リポジトリと前提」参照）。

- device（必須）: [デバイスの型番を小文字・ハイフン区切りで入力。例: grove-water-level-sensor]

- interface（必須）: [i2c / spi / gpio のいずれかを記入]

- プロトタイピングリポジトリのパス（必須）: [実機動作確認済みのコードがあるローカルリポジトリのパス。例: ../chirimen-i2c-tutorial-base]
- index.jsの元にするファイル（任意）: [上記リポジトリ内のファイル名。削除した場合はClaudeCodeが
  候補ファイルを一覧で提示し、どれを使うかユーザーに確認します]
- 個人Forkした chirimen-drivers のローカルパス（必須）: [例: ../chirimen-drivers]
